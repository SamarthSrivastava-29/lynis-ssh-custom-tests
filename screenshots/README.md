# Screenshots

Add genuine screenshots captured from your own Ubuntu VM here.

Suggested evidence:
1. Lynis version and installation.
2. `lynis show includedir` and `lynis show commands`.
3. The custom tests file in your editor.
4. The custom audit output before applying configuration changes.
5. The relevant SSH configuration after changes.
6. The audit output after re-running the tests.
7. Relevant `/var/log/lynis.log` entries.

Do not include generated terminal mockups as if they were authentic command output. If a screenshot is illustrative, label it clearly as an illustration. Remove private information before publishing.
